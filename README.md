# Glassco Connect — ITMS

Mobile-first IT asset lifecycle management for Glassco.

## Local development

```powershell
pnpm install
pnpm dev
```

ITMS uses `http://127.0.0.1:5174/`. Port `5173` is reserved for Glassco PRISM.

The first stage is localhost-only. Firebase will be connected later under the company-owned `dev@glasscolabs.com` account after local acceptance.
