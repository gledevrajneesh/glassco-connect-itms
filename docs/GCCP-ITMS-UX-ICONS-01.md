# GCCP-ITMS-UX-ICONS-01

- One internal SVG icon system with no external package or network dependency
- Purpose-specific icons for dashboard, masters, inventory, allocation, maintenance, assurance and reports
- Product-specific icons for ITMS, support desk, requests, service tickets and visitor management
- Consistent vector styling in launcher, sidebar, dashboard and operational empty states
- Placeholder arrows, geometric glyphs and text monograms are retired from primary navigation and module thumbnails
