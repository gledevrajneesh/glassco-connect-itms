# Glassco CONNECT ITMS and IT Support Desk — Release closure

Release date: 14 September 2026  
Firebase project: `glassco-connect-itms-dev`

## Included

- Shared User Master, group-wise access allocation and app-level allow/revoke controls.
- Firestore-backed operational stores with real-time listeners after controlled migration.
- Inventory, custody, onboarding/offboarding, maintenance, assurance and retirement workflows.
- Portal and email ticket creation, HTML notifications, assignment updates and ratings.
- Portal/email attachments with controlled Google Drive hand-off.
- Search, filters, sticky headers, compact reporting and downloadable KPI data.
- Support agent roster, category routing, SLA targets, escalation recipients and KPI ownership.
- Route-level lazy loading to reduce initial application payload.
- Mailbox bridge health heartbeat and managed Firestore backup command.

## Required operational controls

- Confirm every row in the cloud migration register is `Migrated` and `Reconciled`.
- Run `pnpm backup:firestore -- -Bucket gs://<approved-backup-bucket>` after the backup bucket and retention policy are approved.
- Confirm `supportBridgeHealth/gmail` records a recent `Healthy` heartbeat.
- Review failed records in `supportMailQueue`, attachment intake collections and delivery history.
- Perform and evidence a Firestore restoration drill before treating backups as production recovery.
