# GCCP-ITMS-BUILD-03 — Goods Receipt, Inspection and Asset Registration

## Scope

- Automatic GRN generation
- Vendor, invoice and purchase-order references
- Incoming type, model, quantity and accountable receiver
- Accepted, quarantined and rejected inspection outcomes
- Automatic individual Glassco Asset ID generation
- Serial number, configuration, stock location, cost and condition
- Accepted-quantity control prevents over-registration
- Responsive catalogue, goods receipt and asset register workspace

Only accepted receipt quantities can be converted into stock assets. Quarantined and rejected deliveries remain visible but cannot enter normal inventory.
