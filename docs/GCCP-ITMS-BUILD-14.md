# GCCP-ITMS-BUILD-14 — Reports & Analytics

- Live management dashboard for inventory, custody, maintenance and assurance.
- Asset portfolio quantity and acquisition value by Item Group.
- Standard reports: asset register, current custody, maintenance, verification/exceptions and disposal/write-off.
- Management extensions: repair history, user-wise and department-wise asset/expenditure summaries, Item Group value summary and highest-value asset ranking.
- Dashboard rankings show the highest-value users and assets; repair expenditure remains distinct from asset acquisition value.
- Item Group-first parameters plus location, department, status and from/to dates.
- On-screen Excel-style report table, CSV download and print/PDF action.
- All results are derived from existing lifecycle stores; no duplicate reporting records are created.
