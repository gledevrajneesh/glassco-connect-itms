# GCCP-ITMS-BUILD-07 — Transfer & Return Control

## Locked controls

- Transfers and returns use governed movement records rather than overwriting allocations.
- The current allocated asset is selected before the target employee.
- Transfers retain the previous and new custodian, planned/effective dates and reason.
- Returns move assets to `Returned - inspection pending`; inspection is required before stock availability.
- IT Asset Manager and IT Head approvals are mandatory for final custody change.
- Every request and approval timestamp remains visible in the movement register.
- Completed movements feed the two-way Employee–Asset Relationship Ledger.
