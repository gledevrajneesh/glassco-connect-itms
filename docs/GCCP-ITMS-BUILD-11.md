# GCCP-ITMS-BUILD-11 — User IT Asset Profile

- User Master employee code opens the dedicated IT asset profile.
- Current custody is calculated from the central user–asset lifecycle engine.
- Allocation, replacement, transfer and return history remains visible.
- Repair, damage, breakage, loss, theft and other escalations attach to the governed Asset ID.
- Loss/theft moves the asset to Missing - investigation; repair/damage/breakage moves it to Under repair.
- Incident date, severity, notes, status and closure remain recorded.
