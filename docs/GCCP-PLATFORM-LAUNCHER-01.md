# GCCP-PLATFORM-LAUNCHER-01 — Post-login Application Launcher

## Locked flow

1. User authenticates to Glassco Connect.
2. The platform resolves assigned application access.
3. The application catalogue is displayed.
4. Authorized applications are highlighted and interactive.
5. Unauthorized applications remain muted and cannot be opened.
6. Application-level roles are evaluated after an authorized application opens.

The localhost development identity currently has ITMS access. Authentication and centralized access records will be connected later without changing this navigation model.
