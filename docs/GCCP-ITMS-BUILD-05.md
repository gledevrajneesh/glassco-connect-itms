# GCCP-ITMS-BUILD-05 — Employee–Asset Relationship Ledger

- Two-way user and asset custody views
- Current custody calculated from approved allocation transactions and asset state
- Full historical allocation, temporary issue and replacement lineage
- Search by employee identity or asset identity/model
- Uses existing canonical User IDs and Asset IDs; no duplicate relationship records
- Foundation for returns, transfers, onboarding, offboarding and reconciliation
