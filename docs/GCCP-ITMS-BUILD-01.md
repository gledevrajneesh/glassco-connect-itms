# GCCP-ITMS-BUILD-01 — Shared Organisation Masters

## Scope

- Department Master
- Location Master
- User Group Master
- Shared User Master
- Department-first user filtering
- Active, inactive and reactivation lifecycle
- Browser-local persistence for localhost development
- Responsive desktop, tablet and mobile operation

The persistence boundary is intentionally isolated so it can later be replaced by the company-owned Firebase project without redesigning the user interface.
