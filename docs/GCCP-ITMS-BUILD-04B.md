# GCCP-ITMS-BUILD-04B

Allocation lifecycle and history:

- Allocation reason: new allocation, replacement or temporary issue
- Replacement requires category selection first, followed by an asset currently held by the employee in that category
- Dual approval remains mandatory
- Final replacement approval allocates the new item and moves the old item to `Returned - inspection pending`
- Every allocation preserves request, Asset Manager approval and IT Head approval/custody timestamps
- Existing allocation records remain compatible and display as new allocations
