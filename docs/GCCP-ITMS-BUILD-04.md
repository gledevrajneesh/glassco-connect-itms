# GCCP-ITMS-BUILD-04 — Allocation and Custody Control

## Scope

- Department-first active employee selection
- Single or multiple eligible asset selection
- Automatic allocation reference generation
- IT Asset Manager approval followed by IT Head approval
- Assets remain unavailable to competing requests once committed
- Asset status changes to Allocated only after both approvals
- Append-preserving custody records ready for return and transfer history
- Responsive desktop, tablet and mobile workflow

The localhost development identity can exercise both approval steps for testing. Production authorization will enforce role separation when centralized identity is connected.
